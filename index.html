المرجع الهندسي التفاعلي الشامل لربط السكاشن الأربعة (من أساسيات الشبكات وحتى الـ Switching والـ VLANs)

🌐 أولاً: السيشن 1 & 2 (أساسيات الشبكات ونموذج OSI والـ IP)
📖 الشرح والمفاهيم الأساسية

• تعريف الشبكة: ربط الأجهزة بهدف المشاركة[cite: 1].

• نموذج OSI (7 Layers): هيكل تنظيمي لتقسيم مهام الاتصال من التطبيقات وحتى الكابلات الفيزيائية.

• عنونة IPv4 & Subnetting: استخدام عناوين منطقية لتوجيه البيانات عبر الـ IP مع تقسيم الشبكات عبر الـ Subnet Mask.

💡 مثال واقعي وتطبيقي

شبكة منزلية أو مكتبية (LAN): عندما تربط حاسوبك بطابعة عبر راوتر منزلي، يقوم الراوتر بمنحك عنوان IP محلي لتتواصل الأجهزة داخل نفس النطاق، بينما يتم ربط الفروع البعيدة عبر شبكات واسعة (WAN) مثل الإنترنت.

🚀 ثانياً: السيشن 3 (طبقة النقل، TCP/UDP، والـ Sockets)
📖 الشرح والمفاهيم الأساسية

• القاعدة الذهبية: "IP finds the host. Layer 4 finds the application."

• TCP vs UDP: الأول موثوق وبطيء نسبياً مع ترويسة متغيرة (20-60 بايت) ويستخدم 3-Way Handshake؛ والثاني سريع وخفيف بثابت (8 بايت).

• الـ Sockets والبورتات: اتحاد الآي بي مع البورت لتحديد عنوان الاتصال الكامل. أمثلة البورتات مثل 80 للويب غير الآمن، 443 للويب الآمن، و 53 للـ DNS.

💡 مثال واقعي وتطبيقي

تصفح موقع بنكي: يتم فتح اتصال آمن عبر بروتوكول TCP وبورت 443 لضمان عدم ضياع أي بايت، وتكوين سوكت كامل مثل:

192.168.1.10:49153 -> 142.250.190.46:443

بينما عند بث فيديو مباشر (Live Stream)، يُفضل استخدام UDP لتجنب التقطيع (Buffering).

⚙️ ثالثاً: السيشن 4 (Switching, VLANs, Access/Trunk, & STP)
📖 الشرح والمفاهيم الأساسية

• آلية السويتش: يعمل في Layer 2 مع الإطارات (Frames)[cite: 12] ويبني جدول MAC Address Table بالتعلم (Learning) والتوجيه (Forwarding) بمدة احتفاظ 300 ثانية (Aging Time).

• الـ VLANs: تقسيم السويتش برمجياً لشبكات افتراضية معزولة لتصغير نطاق البث وزيادة الأمان.

• Access vs Trunk: بورت الـ Access ينقل فيلان واحدة للأجهزة الطرفية (Untagged)[cite: 18]؛ بينما بورت الـ Trunk ينقل عدة فيلانز بين السويتشات باستخدام التغليف 802.1Q (Tagged)[cite: 18].

• بروتوكول STP: لمنع عواصف البث والحلقات الشبكية عبر غلق المسارات المكررة مؤقتاً[cite: 21].

💡 مثال واقعي وتطبيقي

شركة متعددة الأقسام (IT و HR):

  • تم ربط أجهزة قسم الـ IT ببورتات Access Port تابعة لـ VLAN 10.
  • تم ربط السويتش الرئيسي بالسويتش الفرعي عبر كابل Trunk Port يحمل بيانات الفيلانز معا بتغليف 802.1Q[cite: 18].
  • وجود كابل احتياطي بين السويتشات لا يسبب مشاكل بفضل حماية بروتوكول STP الذي يبقيه في وضع الاستعداد[cite: 21].
🎬 رابعاً: السيناريو الشامل (رحلة البيانات المتكاملة عبر السكاشن الأربعة)
قصة رحلة البيانات من جهازك وحتى سيرفر الإنترنت

تخيل أنك جالس في مكتبك وتريد فتح موقع ويب آمن، لتتداخل السكاشن الأربعة معاً في أجزاء من الثانية:

1. التجهيز وتحديد الشبكة (السيشن 1 & 2): يتم تهيئة البيانات وتوليد عناوين الـ IP المناسبة لمسار الخروج.

2. النقل والموثوقية (السيشن 3 - Layer 4): يتم استخدام بروتوكول TCP وإجراء المصافحة الثلاثية (3-Way Handshake)، وتحديد البورت 443 وإنشاء الـ Socket الكامل.

3. التبديل والفلترة والفيلانات (السيشن 4 - Layer 2): تغلف البيانات في Frames[cite: 12] وتمر عبر بورت Access الخاص بفيلان الموظفين، ثم تسافر عبر كابل Trunk بين السويتشات[cite: 18] محمية بـ STP[cite: 21]، لتسافر أخيرًا عبر الإنترنت وتصل للوجهة بنجاح!
